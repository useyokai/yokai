# Security policy

## Reporting a vulnerability

In the repository's **Security and quality** tab, open **Advisories** and select
**Report a vulnerability**. If the form is unavailable, contact a repository
maintainer privately before sharing details. Keep suspected vulnerabilities
out of public issues and pull requests while the maintainers investigate.

Include the affected commit, your Windows version, the expected and observed
behavior, and any reproduction steps that use synthetic data. Remove
credentials, personal information and real Instance data from attachments.

## Supported versions

Yokai is pre-alpha. Reports against the current `main` branch help maintainers
triage issues. The project has no maintained release branches.
